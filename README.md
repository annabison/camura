# Residenza Ca' Mura

Sito ufficiale di Residenza Ca' Mura a Cittadella. Landing page multilingua (IT/EN/ES) con contenuti essenziali e aggiornamenti in corso.

**Sito:** https://annabison.github.io/camura

## Caratteristiche

- Home in italiano, inglese e spagnolo
- Banner/hero con immagine di copertina
- Navigazione con selettore lingua
- Layout responsive (mobile/tablet/desktop)

## 🛠 Tech Stack

Progetto realizzato con approccio *static-site* per massimizzare velocità e sicurezza, minimizzando i costi di manutenzione.

- **Core:** HTML5, CSS3 (Sass), Vanilla JS.
- **Template Base:** [Landed](https://html5up.net/landed) by HTML5 UP.
- **Hosting:** GitHub Pages.
- **Multilingua:** Duplicazione strutturale (IT/EN/ESP).
